# 👨‍💼 Cadastro de Funcionários

Projeto desenvolvido com foco no **cadastro de funcionários** para uma empresa de vendas, incluindo **cálculo de comissões** e **aumento salarial** com base em regras específicas.

Este sistema foi iniciado como parte de um trabalho acadêmico do curso de **Sistemas de Informação/Análise e Desenvolvimento de Sistemas**, com a intenção de ser expandido no futuro para integrar soluções mais completas, como o projeto **AUTOPET**.

---

## 💡 Objetivo

O sistema tem como finalidade facilitar o gerenciamento de colaboradores, permitindo:

- Cadastro e listagem de funcionários
- Cálculo automático de comissões de vendas
- Aplicação de aumentos salariais com base em critérios definidos

## 🐾 Integração Futura: Projeto AUTOPET

Este projeto será futuramente integrado ao **AUTOPET** — um dispenser automatizado de ração para pets que:

- Controla o peso do animal
- Calcula a quantidade ideal de ração com base em parâmetros configuráveis
- Libera a porção correta de forma automatizada

A ideia é criar uma **plataforma unificada**, onde o controle de funcionários e automações como o AUTOPET possam ser gerenciados de forma centralizada.
